## Projects

### Kafka → ClickHouse

**Real-time streaming pipeline**

`Kafka` · `Python` · `ClickHouse` · `Docker`

Streams mock user events from Kafka into ClickHouse using **Kafka Engine tables + Materialized Views**, with the entire pipeline containerized for easy reproduction.

---

### ClickHouse Metrics Extractor

**Automated database metrics pipeline**

`Airflow` · `Python` · `ClickHouse` · `Docker`

Extracts ClickHouse system metrics hourly, transforms them into daily snapshots, and orchestrates the pipeline using Airflow.

---

### COVID-19 Data Pipeline

**End-to-end ETL pipeline**

`Airflow` · `Python` · `PostgreSQL` · `Docker`

Ingests data from an external API, orchestrates scheduled transformations with Airflow, and stores the resulting datasets in PostgreSQL.

---

### TrendLite

**Real-time analytics dashboard**

`Python` · `Streamlit` · `ClickHouse`

A live retail analytics dashboard for exploring KPIs, product performance, and trends using ClickHouse-backed queries.
